## 2. Logic Chain

1. From **Observation 1**, `SlipMaterial` requires fields for `shaderGraphPath`, `graphFloatParams`, `graphVectorParams`, `graphTextureParams`, and `graphProperties`, as well as methods `LoadShaderGraph`, `SetGraphFloat`, `SetGraphVector`, `SetGraphTexture`, and their corresponding getters.
2. From **Observation 2**, dynamic shaders generated by `ShaderGraphCompiler::Compile` are instantiated using `SlipShader::CreateFromSource`. Because `CreateFromSource` allocates a `new SlipShader()`, resource ownership must be explicitly managed. Using `std::shared_ptr<SlipShader> m_CustomShader` with a custom deleter (`s->destroy(); delete s;`) avoids double-frees when `SlipMaterial` instances are copied (e.g. in `InspectorPanel.cpp`) and guarantees `glDeleteProgram` is called upon destruction or graph re-assignment.
3. From **Observation 3**, texture units 0 through 19 are strictly reserved for PBR textures, CSM shadow array, DDGI, AO, emissive, opacity, and reflections. Binding custom graph texture samplers starting at unit 20 (up to 31) guarantees zero collision with engine lighting subsystems.
4. From **Observation 4**, `.mat` file serialization must write `shaderGraph:`, and both `graphFloat_`/`graphVector_`/`graphTexture_` and `graphParam.` formats. The parser in `loadMatFromFile` supports both formats and calls `init()` which invokes `LoadShaderGraph(shaderGraphPath)`.
5. From **Observation 5**, viewport rendering routes all mesh draws through `SlipRenderQueue::Flush()`. To execute custom Shader Graph programs, `Flush()` must select `(cmd.material && cmd.material->shader) ? cmd.material->shader : SlipShaderLibrary::Get(sType)`.

## 3. Caveats

- **GL Context Requirement**: Calling `SlipShader::CreateFromSource` requires an active OpenGL context. In headless testing without an initialized OpenGL context, `glad_glCreateProgram` is null, which `init()` already guards against (`if (!glad_glCreateProgram) return;`).
- **Texture Unit Limit**: Custom texture parameters are bound to units 20 through 31 (up to 12 custom textures). Modern GPUs support at least 48 to 192 units. If a graph exceeds 12 texture samplers, units will clamp at 31 to prevent GL error.
- **Topological Sorting**: Assumes `ShaderGraphCompiler` emits valid GLSL strings for Lit and Unlit graphs, as specified in Explorer M2_1's design contract.
